# Pilot Evidence Quicklink

Give a reviewer one short public link that routes them to three countable pilot-evidence actions while preserving zero-user, zero-feedback, and zero-business-case baselines until public evidence exists.

Public page: [https://sunnnn2005.github.io/data-quality-agent/pilot-evidence-quicklink.html](https://sunnnn2005.github.io/data-quality-agent/pilot-evidence-quicklink.html)

| Submit an anonymized business problem | 10 | `business_case_feedback_items` | [Open](https://github.com/sunnnn2005/data-quality-agent/blob/main/docs/business-case-intake.md) | [Submit](https://github.com/sunnnn2005/data-quality-agent/issues/new?template=business_case_review.md) | anonymized public issue with no raw production data |

## Evidence Fields

### Try the public demo

- which screen or result you inspected
- one thing that was useful or credible
- one confusing or missing part
- permission to count this as public feedback

### Run the container or local demo

- command, URL, or page used
- environment
- observed result
- permission to count this as an external run

### Submit an anonymized business problem

- workflow affected
- data-quality failure mode
- why it matters operationally
- permission to count anonymized business-case evidence
