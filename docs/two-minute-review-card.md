# Two-Minute Review Card

Give a busy reviewer the shortest safe path to produce the first countable public feedback item without inflating users, stars, or adoption.

Public card: [https://sunnnn2005.github.io/data-quality-agent/two-minute-review-card.html](https://sunnnn2005.github.io/data-quality-agent/two-minute-review-card.html)

## Copy-Ready Message

```text
Could you spend 2 minutes reviewing my Data Quality Agent demo? Open this card, inspect one result, and leave one concrete public note if you are comfortable: https://sunnnn2005.github.io/data-quality-agent/two-minute-review-card.html
```

## Micro-Steps

1. [Open the public demo](https://sunnnn2005.github.io/data-quality-agent/) - Open the hosted demo and inspect the support-ticket data-quality result. `counts_as_outcome=False`
2. [Pick one useful or confusing detail](https://sunnnn2005.github.io/data-quality-agent/first-external-review-card.html) - Choose one concrete observation about the report, agent behavior, guardrails, or UI. `counts_as_outcome=False`
3. [Submit public evidence](https://github.com/sunnnn2005/data-quality-agent/issues/new?template=demo_feedback.md) - Open the feedback issue template and include permission/no-private-data checks. `counts_as_outcome=False`

## Required Evidence

- what page, command, or route was reviewed
- one concrete observed result
- one useful, confusing, or missing detail
- permission to count publicly
- confirmation that no private data was posted
