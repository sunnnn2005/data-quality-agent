# Data Quality Agent v0.2.0

Data Quality Agent v0.2.0 turns the first public demo into a stronger resume-evidence release. The core product is still intentionally conservative: it demonstrates a realistic business data-quality workflow without claiming external users, customer feedback, or enterprise production adoption.

## What changed

- Added a PostgreSQL-backed LLM agent route: `POST /postgres/support-tickets/agent-report`.
- Reused the read-only support-ticket database adapter for both deterministic reports and agent reports.
- Added safe disabled fallback when the LLM agent route is called without `OPENAI_API_KEY`.
- Expanded the public outcome evidence manifest with a verified `postgres-agent-route` claim.
- Expanded scheduled public evidence health checks from 6 to 7 checks, including source verification for the PostgreSQL agent route.
- Updated adoption metrics and history to reflect 52 passing CI tests.
- Kept feedback and user metrics at an honest zero baseline until public evidence exists.
