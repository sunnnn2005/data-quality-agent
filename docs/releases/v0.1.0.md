# Data Quality Agent v0.1.0

Data Quality Agent v0.1.0 is the first public release of the project.

## What is included

- Public demo: <https://sunnnn2005.github.io/data-quality-agent/>
- Container image: `ghcr.io/sunnnn2005/data-quality-agent:latest`
- Support-ticket case study: `docs/support-ticket-case-study.md`
- Machine-verified artifact: `docs/verified-support-ticket-result.json`
- Read-only PostgreSQL Docker Compose demo
- OpenAI-compatible LLM tool-calling agent
- Source-cited business-rule retrieval
- Bounded CSV business-data upload
- Auditable run traces
- Ticket-ready Markdown incident report export
- Three-scenario evaluation harness
- Public feedback issue template

## Boundaries

- The default path does not require paid APIs or model keys.
- External model calls are opt-in through `OPENAI_API_KEY`.
- PostgreSQL access is disabled by default and uses a read-only adapter.
