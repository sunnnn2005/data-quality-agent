# Data Quality Agent v0.3.0

Data Quality Agent v0.3.0 packages the project as a stronger AI-engineering resume signal. The release focuses on proving that the system is an LLM agent with controlled tools, state, evidence-backed reporting, safety boundaries, and public verification artifacts. It still avoids claims that are not proven yet: no external users, customer feedback, enterprise production deployment, or paid-model benchmark results are claimed.

## What changed

- Added a CI-verified LLM agent capability matrix with 13 implemented checklist items, 4 partial maturity areas, 9 allowed tools, and explicit not-claimed production adoption.
- Expanded the live project scorecard to connect the public demo, release, container image, 88 passing tests, 47 verified resume claims, 11 reviewer paths, and application evidence links.
- Updated recruiter-facing and application-facing artifacts so project claims are backed by public URLs instead of unsupported resume language.
- Kept the project honest about traction: GitHub stars, forks, feedback issues, confirmed users, and reproducible feedback remain tracked from public sources instead of estimated.
- Preserved the read-only PostgreSQL agent route, deterministic fallback behavior, agent safety boundaries, trace observability, business-rule retrieval, and report guardrails from earlier releases.
