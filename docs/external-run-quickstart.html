Required evidence fields

These 8 fields make the result countable without asking for private data.

  • reviewer_role - example: student developer, data analyst, recruiter, mentor
  • path_tried - example: public_demo_review or container_smoke_run
  • environment - example: macOS 15, Docker Desktop 4.x, Chrome
  • commands_or_urls_used - example: docker compose up --build
  • observed_result - example: health returned ok and support-ticket report loaded
  • usefulness_score_1_to_5 - example: 4
  • main_feedback - example: setup was clear, but report explanation could be shorter
  • permission_to_count_publicly - example: yes
Privacy boundary

No private business data

  • Do not ask reviewers to upload private business data.
  • Do not store raw reviewer datasets in this repository.
  • Ask for anonymized field names, command output summaries, and screenshots only when safe.
  • Count only public GitHub issues where the reviewer gave permission to count the run.
