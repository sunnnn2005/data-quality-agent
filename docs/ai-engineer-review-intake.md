## Review Questions

1. Does the LLM tool calling path choose tools based on evidence rather than following a fixed workflow?
2. Are tool results fed back into the model before the final answer?
3. Is the output structured enough for another API or reviewer to verify?
4. Are guardrails, redaction, and read-only database boundaries visible?
5. Would this project credibly support an AI Engineer Intern interview discussion?
6. What single improvement would make the project more convincing?
